# college-draft-explorer

A dashboard for asking how MLB draftees' careers turn out, depending on where and how they were
drafted. It covers draft classes 2012-2025 and looks at whether players reached MLB, how long it
took, and career WAR, broken down by school, conference, school type, position, age at draft, draft
slot and signing bonus.

Status: ingestion and data profiling. See [docs/DATA_PROFILE.md](docs/DATA_PROFILE.md) for
what the raw data contains and how complete it is.

## Data sources

- **MLB Stats API** (`statsapi.mlb.com`): draft results and player bios.
- **[Baseball-Reference](https://www.baseball-reference.com/)**: WAR tables (via `pybaseball`),
  and the draft pages for 2012-2017, which supply the signed flag and signing bonus that the MLB
  API lacks for 2012-2016. Pages are fetched at most one every 7 seconds and cached, so each page is
  requested once. Data courtesy of Baseball-Reference / Sports Reference LLC.
- **Wikipedia**, [List of NCAA Division I baseball programs](https://en.wikipedia.org/wiki/List_of_NCAA_Division_I_baseball_programs)
  (CC BY-SA 4.0): Division I membership and conference, from two pinned revisions (June and
  September 2024) to capture the July 2024 realignment.

`reference/schools.csv` maps every non-high-school school name in the draft data to a canonical
school, type (4YR/JC), division and conference. It is generated by `make schools` and committed;
rows edited by hand should set `type_source` to `manual`, and re-runs keep them.
`reference/conference_moves_2024.csv` lists the July 2024 conference changes.

## Setup

Requires [uv](https://docs.astral.sh/uv/) (it installs Python 3.12 if needed).

```sh
make setup                # install dependencies
make pull && make profile # MLB draft, people, WAR; write docs/DATA_PROFILE.md
make all-data             # everything: pull, pull-bbref (~30 min first time), backfill, schools, profile
make test lint            # offline tests, ruff
```

Raw responses are cached under `data/raw/` and flattened tables are written to `data/interim/`
(both git-ignored). A second run reads from the cache and makes no network calls. Pass
`--force` to a pull script to re-download.

If Baseball-Reference returns 429 or 403, `pull-bbref` stops immediately rather than retrying.
Wait an hour and re-run it; pages already cached are not fetched again.
