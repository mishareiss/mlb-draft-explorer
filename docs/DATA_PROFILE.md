## Notes for Task 2

1. `signingBonus` is null for every pick in [2012, 2013, 2014, 2015, 2016]; bonus analysis is effectively limited to the other years.
2. `school.schoolClass` (HS/4YR/JC level) is mostly null in [2012, 2013, 2014, 2015, 2016, 2017, 2019]; school type must be inferred (e.g. from school name) for those years or left unknown.
3. `schoolClass` mixes two encodings: `4YR JR`/`JC J2`/`HS SR` and bare `JR`/`SR`/`SO` (level missing). Needs a mapping table.
4. `pickValue` (slot value) is a string, absent before 2017, partly present after, and `"0"` appears as a placeholder in some years; treat `0` as missing.
5. Supplemental rounds use non-numeric labels (`CB-A`, `1C`, `PPI`, `SUP-2`, ...), so order by `pickNumber` (overall), not `pickRound`. Numeric rounds max out at {2012: 40, 2013: 40, 2014: 40, 2015: 40, 2016: 40, 2017: 40, 2018: 40, 2019: 40, 2020: 5, 2021: 20, 2022: 20, 2023: 20, 2024: 20, 2025: 20}.
6. 1,295 people appear in more than one draft row. Task 2 must pick one row per person (e.g. last/signed draft) before computing outcome rates.
7. `person.draftYear` differs from the row's draft year on 16.0% of picks, including people drafted only once in this window: it is a person-level field that can point to drafts outside 2012-2025. Ignore it; use `draft_year`.
8. Position in the draft payload matches the current `/people` position on 100.0% of rows, so it is likely the current position, not position at draft time.
9. School names are not normalized (`TCU` vs `Texas Christian`, `LSU` vs `Louisiana State`), and `school_state` is empty for 2012-2016 (some names embed it, e.g. `(FL) HS`). Conference is not in the payload at all; it needs a school lookup.
10. No draft date, only the year: age-at-draft needs a draft-date table (June through 2020, July from 2021). WAR `mlb_ID` is float with nulls only on pre-1950 rows; cast to int after dropping nulls.
